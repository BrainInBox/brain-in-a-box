Le guide

Tu montres, il te dit où cliquer.

Tu bloques dans un logiciel (Odoo, Sage, Excel, le site des impôts…) ? Bibo ouvre une petite fenêtre à côté. Claude regarde ta fenêtre et te dit où cliquer, une étape à la fois, en entourant l’endroit. Tu cliques, tu dis « C’est fait », il passe à la suite.

  1. 1

    Dis-lui ce que tu veux faire

    Le logiciel, et ce que tu veux y faire, avec tes mots : « faire une facture à un client », « donner un accès à ma comptable ».

  2. 2

    Montre ta fenêtre, suis l’étape

    Il te dit où cliquer et l’entoure en rouge sur ta capture. Coincé ? « Je suis bloqué » : dis ce qui coince, il regarde à nouveau. À la fin, il peut ranger la marche à suivre dans ton cerveau, pour la prochaine fois.

Ce qu’il te faut, ce qui part

Le guide marche avec ton propre abonnement Claude (Pro, environ 20 € par mois chez Anthropic) : Brain in a Box ne fournit pas Claude et ne te fait rien payer. Les captures de ta fenêtre partent chez Anthropic pour que Claude les lise ; Bibo n’en garde rien. Évite d’y montrer des mots de passe.

Ce que Bibo installe

Tout ce qu’il faut, rien de plus.

Claude Code pour travailler avec Claude, Obsidian pour feuilleter tes notes, et une mémoire pour qu’il s’en souvienne. Bibo n’installe que ce qui manque, une étape après l’autre. Tes notes et ta mémoire restent sur ton ordinateur : ce qui en sort.

Installer

Installer l’app.

Choisis ton système. L’app est une préversion, pas encore signée par Apple ni par Microsoft : la première fois, ton ordinateur te met en garde. Voici comment passer ce message.

Windows Mac Linux

Sur Windows

  1. Télécharge l’installeur

    Le fichier : Brain-in-a-Box_windows-x64-setup.exe

    Télécharger pour Windows

  2. Garde le fichier, s’il le faut

    Ton navigateur peut dire que le fichier « n’est pas fréquemment téléchargé » (isn’t commonly downloaded). Dans Edge : clique sur « … » à côté du fichier, puis Conserver (Keep). S’il insiste, Afficher plus (Show more), puis Conserver quand même (Keep anyway).

    Ensuite, ouvre le fichier : dans les téléchargements du navigateur, ou dans ton dossier Téléchargements.

  3. « Windows a protégé votre ordinateur »

    Un message bleu s’affiche (Windows protected your PC). Clique sur Informations complémentaires (More info).

  4. Exécuter quand même

    Le nom du fichier apparaît, avec « Éditeur inconnu » (Unknown publisher). Clique sur Exécuter quand même (Run anyway).

  5. Clique sur Suivant, puis Fermer

    L’assistant installe Bibo en quelques secondes, pour toi seul. Laisse « Lancer Bibo maintenant » coché et clique sur Fermer : Bibo s’ouvre. Pour le retrouver plus tard : l’icône « Brain in a Box », sur ton bureau ou dans le menu Démarrer.

    Plus tard, pendant que Bibo installe le reste, Windows peut te demander une autorisation pour Git ou Python (« Voulez-vous autoriser cette application à apporter des modifications… », Do you want to allow this app…) : clique sur Oui (Yes).

Pourquoi ce message ?

Windows (SmartScreen) prévient pour toute app qui n’est pas signée avec un certificat de signature de code. La préversion n’en a pas encore. Pour vérifier que ton fichier vient bien du projet : vérifier le fichier téléchargé. Windows bloque sans bouton pour continuer ? Smart App Control.

Sur Mac

  1. Télécharge l’app

    Un seul fichier pour les puces Apple et Intel : Brain-in-a-Box_macos-universal.dmg

    Télécharger pour Mac

  2. Glisse-la dans Applications

    Ouvre le fichier téléchargé (dans Téléchargements). Une fenêtre s’ouvre : glisse Brain in a Box sur le dossier Applications.

  3. Ouvre-la une première fois

    Ouvre Brain in a Box depuis Applications. macOS l’arrête avec un message : Apple n’a pas pu vérifier l’app. Clique sur Terminé (Done ; Annuler sur macOS 13 et 14), surtout pas sur « Placer dans la corbeille » (Move to Trash).

  4. Autorise-la dans les Réglages

    Fais-le tout de suite : le bouton disparaît au bout d’une heure environ. Ouvre Réglages Système › Confidentialité et sécurité (System Settings › Privacy & Security). Descends jusqu’à « Sécurité » : à côté de Brain in a Box, clique sur Ouvrir quand même (Open Anyway), puis confirme avec ton mot de passe.

    C’est tout : ensuite, l’app s’ouvre normalement. Pour la retrouver : Cmd + Espace, tape « Brain », puis Entrée.

Pourquoi ce blocage ?

Pour qu’un Mac ouvre une app sans prévenir, il faut qu’Apple l’ait signée, ce qui demande un compte développeur Apple. La préversion ne l’est pas encore : macOS dit seulement qu’il ne la connaît pas. Pour vérifier que ton fichier vient bien du projet : vérifier le fichier téléchargé.

Sur Linux

Deux formats, au choix. Le plus simple : l’AppImage, rien à installer.

  1. Télécharge l’AppImage

    Le fichier : Brain-in-a-Box_linux-x86_64.AppImage

    Télécharger l’AppImage

  2. Rends-la exécutable

    Clic droit sur le fichier › Propriétés › active Exécutable comme un programme.

    Dans un terminal, c’est pareil : chmod +x Brain-in-a-Box_linux-x86_64.AppImage

  3. Double-clique dessus

    Sur Ubuntu 22.04 et 24.04, rien d’autre à installer : Bibo s’ouvre.

    Rien ne se passe, sur une autre distribution ? Il manque sans doute FUSE : installe-le avec sudo apt install fuse3, ou lance l’app avec ./Brain-in-a-Box_linux-x86_64.AppImage --appimage-extract-and-run

Ou le paquet .deb

Télécharge Brain-in-a-Box_linux-amd64.deb, puis, dans un terminal ouvert dans ton dossier Téléchargements :

sudo apt install ./Brain-in-a-Box_linux-amd64.deb

Ensuite, ouvre Brain in a Box depuis le menu des applications. Avec un lecteur d’écran sur Ubuntu 24.04, préfère le .deb : l’AppImage y annonce mal certains éléments.

Télécharger le .deb

Ton mot de passe, une ou deux fois

Pour installer les outils du système qui manquent (git, python3, curl…) et Obsidian, la fenêtre de ton système te demande ton mot de passe. Elle affiche « Brain in a Box installe » et ce qu’elle installe. C’est normal : tape-le. Tout le reste s’installe dans ton dossier personnel.

Une autre distribution (Fedora, Arch…) ? Bibo te dit quoi installer avec ton gestionnaire de paquets.

Bibo, écran par écran

Tu cliques, Bibo installe.

Une fois l’app ouverte, Bibo te guide. Ces captures viennent du robot qui teste l’app chaque nuit sur des ordinateurs neufs, ici un Mac. Sur Windows et Linux, c’est la même fenêtre, avec les étapes de ton système.

  1. Écran 1

    « Salut, moi c’est Bibo ! »

    Bibo annonce le programme : il regarde ce qui manque, installe Claude, te fait connecter ton compte, puis installe le reste. Clique sur Vérifier mon Mac (ou « Vérifier mon PC »).

  2. Écran 2

    « J’ai fait le tour. »

    En quelques secondes, Bibo vérifie ton système, la place libre, internet et ce qui est déjà installé.

    Mon conseil : d’après ce qui est déjà sur ton ordinateur (Claude Code, les apps ChatGPT ou Claude, Hermes…), Bibo te dit en une phrase avec quelle IA ton cerveau travaillera et ce qu’il te faut, sans ouvrir tes fichiers de connexion. S’il voit Hermes, il ne l’installe pas et n’y touche pas.

    • Coche verte : c’est bon.
    • Flèche dans un cercle pointillé : Bibo va l’installer.
    • Point d’exclamation orange : à noter, rien de grave.
    • Croix rouge : à régler avant de continuer. Bibo te dit comment, puis « Revérifier ».

    Clique sur Tout installer.

  3. Écran 3 · optionnel

    « Une option avant de commencer »

    Ton cerveau retrouve tes notes par mots-clés. Avec une clé Voyage AI, il les retrouve aussi par le sens. Pas de clé ? Clique sur Passer (recherche par mots-clés) : tu pourras l’ajouter plus tard.

    Comment avoir une clé, et ce que ça coûte

  4. Écran 4

    « Connecte ton compte Claude maintenant »

    Dès que Claude Code est installé, Bibo te propose de connecter ton compte, si ce n’est pas déjà fait. Clique sur le bouton : une fenêtre Terminal s’ouvre (PowerShell sur Windows), ton navigateur te demande de te connecter à Claude, puis tu reviens. Bibo continue tout seul.

    Connecté, Claude pourra aider Bibo si une étape coince. Tu peux aussi choisir Plus tard.

  5. Écran 5

    L’installation, étape par étape

    Bibo installe seulement ce qui manque, une étape après l’autre, avec une barre de progression. « Détails » montre le journal, si tu es curieux. Ce que tu pourrais avoir à faire :

    • Windows : deux étapes seulement. Windows peut demander une autorisation pour installer Git ou Python : clique sur « Oui » (Yes).
    • Mac : une fenêtre d’Apple s’ouvre pour les outils Apple. Clique sur « Installer » (Install), puis « Accepter » (Agree). Apple télécharge ensuite ses outils, 5 à 15 minutes : ne t’inquiète pas si la fenêtre annonce d’abord plus d’une heure. macOS peut aussi demander l’accès à ton dossier Documents : clique sur « Autoriser » (Allow).
    • Linux : ton mot de passe, pour les outils du système et Obsidian.

    Les deux façons, pas à pas

Si une étape coince

Bibo affiche « Oups, ça a coincé. » et te propose, dans l’ordre :

  1. Réessayer : il relance l’étape.
  2. Demander à Claude de réparer, si ton compte est connecté. Claude lit le journal de l’étape (clés masquées, jamais tes fichiers personnels), puis Bibo te dit ce qui coince et ce qu’il propose. Rien ne change avant que tu cliques sur « Réparer ». S’il met quelque chose de côté, rien n’est effacé : « Remettre comme avant » le remet. Ça utilise un peu de ton abonnement Claude, et tu peux voir exactement ce qui lui est envoyé.
  3. Le plan B, Claude dans le Terminal (PowerShell sur Windows). Bibo t’explique d’abord comment ça se passe. Claude t’explique le problème avec des mots simples et te demande ton accord avant chaque commande. Ses questions sont en anglais : « Yes » veut dire oui, « No » non. Évite « Yes, and don’t ask again » : il ne te demanderait plus ton accord.
  4. Copier le rapport, en dernier recours, et l’envoyer au projet : ouvre un ticket sur GitHub et colle-le. Les clés y sont masquées, mais relis-le avant : un ticket est public.

Claude Code

Ce qu’il fait pour toi

L’outil officiel d’Anthropic : Claude, directement sur ton ordinateur. C’est avec lui que tu travailles, et c’est lui qui se sert de ton cerveau.

Ce que tu as à faire

  • Connecter ton compte, une fois. Bibo ouvre la fenêtre pour toi.
  • Pour te faire guider dans un logiciel : « Guide-moi dans un logiciel », dans Bibo. Pour te présenter à Claude : « Personnaliser mon cerveau », à la fin de l’installation.
  • Pour lui parler tous les jours, il faut aujourd’hui le Terminal (pour les développeurs). Un bouton « Parler à Claude » dans Bibo est en préparation.

Obsidian

Ce qu’il fait pour toi

Pour feuilleter ton cerveau. Tes notes sont de simples fichiers texte, dans le dossier Documents › Brain. Obsidian les affiche joliment, avec les liens entre elles.

Ce que tu as à faire

  • Rien à installer.
  • Pour l’ouvrir sur ton cerveau : le bouton « Ouvrir mon cerveau dans Obsidian », à la fin. Plus tard, dans Obsidian : ouvre un dossier comme coffre (« Open folder as vault ») et choisis Documents › Brain.

La mémoire

Ce qu’elle fait pour toi

Elle range tes notes pour les retrouver vite. Quand tu demandes à Claude « qu’est-ce qu’on avait décidé pour… ? », il cherche dans ta mémoire et te cite la note. (Pour les curieux : c’est GBrain, qui tourne avec Bun.)

Ce que tu as à faire

  • Rien. La nuit, la mémoire se range et se met à jour toute seule, avec une semaine de recul sur chaque nouvelle version. Si une mise à jour casse quelque chose, elle revient en arrière.

Les automatismes et compétences de Claude

Ce qu’il fait pour toi

Des automatismes : quand tu corriges Claude, il note la leçon ; tes séances sont résumées dans ton Journal. Des compétences : le contrôle de nuit (/controle), une recherche rapide sur le web, une page HTML pour expliquer ou présenter quelque chose, la conversion de documents (Word, PDF…) en notes, l’import de ta mémoire ChatGPT ou Claude et « brain-boost », qui t’explique ce que ton installation sait faire.

Ce que tu as à faire

  • Rien. Pour découvrir, demande à Claude : « qu’est-ce que tu peux faire pour moi ? »

Les outils du système

Ce qu’il fait pour toi

Ce dont tout le reste a besoin pour tourner.

Ce que tu as à faire

  • Windows : Python et Git, installés avec ton cerveau. Si Windows demande une autorisation, clique sur « Oui » (Yes).
  • Mac : les outils Apple (git, python3). Une fenêtre d’Apple s’ouvre : clique sur « Installer » (Install), puis « Accepter » (Agree). Ça prend 5 à 15 minutes, même si elle annonce d’abord plus d’une heure.
  • Linux : git, python3, curl, unzip et procps, s’il en manque. Ton système te demande ton mot de passe.

La recherche par le sens : Voyage AI optionnel

Ce qu’il fait pour toi

Sans clé, ton cerveau cherche par mots-clés. Avec une clé Voyage AI, il retrouve aussi une note par le sens, même si tu as oublié les mots exacts.

Ce que tu as à faire, si tu la veux

  1. Crée un compte sur dashboard.voyageai.com.
  2. Ajoute une carte bancaire (menu Billing). Sans carte, Voyage limite à 3 requêtes par minute : trop lent pour ton cerveau.
  3. Crée une clé (menu API Keys). Elle commence par pa-.
  4. Colle-la dans Bibo, avec « Activer la recherche par le sens ». Rien ne presse : ton cerveau marche très bien sans.

Ce que ça coûte : Voyage offre un gros volume gratuit (200 millions de « tokens », des morceaux de mots ; carte demandée), et un cerveau perso en utilise moins de 1 %. Au-delà, Voyage facture au mois. Les tarifs de Voyage.

Vie privée : le texte de tes notes part chez Voyage pour être analysé. Dans leur tableau de bord, règle Organization › Terms of Service sur « Opted Out » pour qu’il ne serve pas à entraîner leurs modèles.

Après l’installation

Et maintenant ?

Fais-toi guider

Dans Bibo, clique sur « Guide-moi dans un logiciel ». Dis ce que tu veux faire, montre ta fenêtre : Claude te dit où cliquer, une étape à la fois. Le guide.

Présente-toi à Claude (15 min)

Clique sur « Personnaliser mon cerveau » à la fin. Une fenêtre s’ouvre avec Claude, qui te pose quelques questions par petits groupes : qui tu es, ton travail, tes projets, les gens avec qui tu travailles, ta façon de travailler. Il remplit ton profil avec tes réponses. Jamais de mot de passe ni de clé : il note seulement où ils sont rangés.

Ouvre ton cerveau

Ton cerveau est un dossier : Documents › Brain. Dedans : ton profil, tes leçons, ton journal, tes projets, tes décisions… Ce sont tes fichiers : tu peux les lire, les modifier, les sauvegarder.

Sur Windows, si ton dossier Documents est protégé contre les rançongiciels, ton cerveau est dans ton dossier personnel, sous Brain.

Corrige-le, il retient

Quand Claude se trompe, dis-le : « désormais… », « la prochaine fois… », « évite de… ». Il retient la leçon pour les fois suivantes.

Le contrôle de nuit

Chaque nuit à 4 h, un script vérifie tes notes : il masque les mots de passe écrits en clair, archive les vieux souvenirs, retire les doublons, et note le reste pour toi. Le matin, la première ligne de Claude dit ce qu’il a fait.

Tape /controle pour qu’il t’explique. Pour défaire une correction : /controle annuler suivi de son identifiant, par exemple S2-261014-02. Tu le trouves dans le compte rendu de la nuit, Profile › controle.md dans ton cerveau. Pour défaire toute la nuit, dis à Claude : « annule le contrôle de cette nuit ».

Les mises à jour

La mémoire se met à jour toute seule, la nuit. L’app se met à jour en téléchargeant la nouvelle version ici : comment faire.

Tes données restent chez toi

Tes notes, ta mémoire et son index sont sur ton ordinateur : pas de serveur, pas de cloud partagé. Ce qui sort : ce que tu dis à Claude et les captures du guide (chez Anthropic, avec ton abonnement), des extraits pour le résumé du jour et le contrôle de nuit (mots de passe et clés masqués avant l’envoi), ce que tu choisis d’importer, masqué de la même façon et trié par Claude, et, avec une clé Voyage, le texte envoyé à Voyage AI.

Ta mémoire

Importe ta mémoire ChatGPT ou Claude.

ChatGPT ou Claude te connaissent déjà. Bibo apporte à ton cerveau ce qu’ils savent de toi : qui tu es, tes préférences, tes projets, les personnes, tes outils, tes décisions, chacun avec sa source. Le bouton « Importer ma mémoire » est à la fin de l’installation, et reste là quand tu rouvres l’app.

Par copier-coller 2 min

  1. Bibo te donne une phrase à copier (« Liste chaque souvenir que tu as enregistré sur moi… »).
  2. Colle-la dans une nouvelle conversation, sur ChatGPT ou sur Claude.
  3. Copie sa réponse avec le bouton Copier de son bloc de code, et colle-la dans Bibo. S’il dit qu’il en reste, écris-lui « Continue » et colle la suite à la fin.

Le mieux pour les souvenirs enregistrés de ChatGPT : son export ne les contient souvent plus.

Avec ton fichier d’export le plus complet

  • ChatGPT : Paramètres › Contrôles de données › Exporter les données. Un e‑mail t’envoie un lien, valable 24 h : télécharge le fichier .zip.
  • Claude : Paramètres › Confidentialité › Exporter les données, sur claude.ai ou l’app de bureau (pas sur le téléphone). Un e‑mail t’envoie un lien, valable 24 h : télécharge le ou les fichiers .zip.
  • Dans Bibo, « Choisir mon fichier d’export ». Plusieurs .zip ? Prends-les tous d’un coup (Cmd‑clic sur Mac, Ctrl‑clic sur PC).

En anglais : Settings › Data controls › Export data, ou Settings › Privacy › Export data. Ton navigateur a ouvert le .zip en dossier (Safari le fait) ? Clic droit sur le dossier › Compresser, puis choisis ce .zip.

Ce qui part, et où

Bibo lit ton export ou la réponse collée sur ton ordinateur, sans rien décompresser, et masque les mots de passe et les clés. D’un export, il garde tes messages, tes souvenirs enregistrés et tes consignes, pas les réponses de l’IA ni les fichiers joints.

Avant d’envoyer quoi que ce soit, il te dit ce qu’il a lu et combien de demandes il fera à Claude, environ une minute chacune (pour un export, tu choisis : Rapide, Normal ou Complet, jusqu’à 10). « Voir exactement ce que j’envoie » te montre le texte. Rien ne part avant « Lancer ». Le texte va à Claude seulement, chez Anthropic, avec ton abonnement : rien ailleurs. Ça compte dans ta limite d’usage, sans frais en plus.

Le résultat : une nouvelle note dans ton cerveau, dossier Imports, à relire (Claude peut se tromper). Aucune note n’est remplacée, et le même export n’est pas importé deux fois.

Sans l’app, ou si tu as installé en ligne de commande : dis à Claude « importe ma mémoire ChatGPT ». Sa compétence importer-memoire fait la même chose, et te demande ton accord avant d’envoyer.

Pour les développeurs : installer en ligne de commande

C’est possible sur Windows, Mac et Linux, en une à quatre lignes : les commandes, système par système.

Mettre à jour

La mémoire se met à jour toute seule, la nuit. L’app, quand une nouvelle préversion sort : télécharge-la ici, puis :

  • Windows : ferme Bibo et lance le nouvel installeur. Il affiche « Mettre à jour Bibo » : clique sur Suivant. Tes notes ne changent pas.
  • Mac : ferme l’app, ouvre le nouveau fichier .dmg, glisse Brain in a Box dans Applications et choisis « Remplacer » (Replace). Ton Mac peut te redemander « Ouvrir quand même », comme la première fois.
  • Linux : remplace l’ancienne AppImage par la nouvelle, et rends-la exécutable comme la première fois. Pour le .deb : la même commande qu’à l’installation, dans ton dossier Téléchargements.

Les automatismes et compétences de Claude : pour l’instant, leur mise à jour se fait en ligne de commande, comme l’installation pour les développeurs. Rouvrir l’app ne suffit pas : Bibo voit qu’ils sont là et n’y touche pas.

Ce que tu as modifié n’est pas perdu. Sur Mac et Linux, un fichier que tu as changé reste tel quel, et la nouvelle version attend à côté, dans ~/.brain-in-a-box/pending. Sur Windows, ton fichier est d’abord copié dans ~\.brain-in-a-box\backups.

Vérifier le fichier téléchargé

Pour les curieux. Chaque préversion publie un fichier SHA256SUMS : calcule l’empreinte de ton fichier et compare-la avec sa ligne. Si elles sont identiques, le fichier est arrivé intact.

# Windows (PowerShell)
(Get-FileHash $HOME\Downloads\Brain-in-a-Box_windows-x64-setup.exe).Hash.ToLower()
# Mac
shasum -a 256 ~/Downloads/Brain-in-a-Box_macos-universal.dmg
# Linux
sha256sum "$(xdg-user-dir DOWNLOAD)"/Brain-in-a-Box_*

GitHub atteste aussi chaque fichier : avec l’outil gh (GitHub CLI), cette commande dit s’il a bien été construit par le projet, depuis sa branche principale (ici pour le fichier Mac ; même chose avec le tien).

gh attestation verify ~/Downloads/Brain-in-a-Box_macos-universal.dmg -R BrainInBox/brain-in-a-box --signer-workflow BrainInBox/brain-in-a-box/.github/workflows/release.yml --source-ref refs/heads/master

Pour les développeurs

Ou installe-le sans l’app.

Pour qui connaît le terminal : le même cerveau, installé par le script du projet. Choisis ton système, copie, colle. Tu ne connais pas le terminal ? Prends l’app, plus haut.

Windows Mac Linux

Windows

Ouvre PowerShell (menu Démarrer, tape « PowerShell »), colle cette ligne, puis Entrée. Pour mettre à jour, la même ligne.

powershell -NoExit -ExecutionPolicy Bypass -Command "irm https://raw.githubusercontent.com/BrainInBox/brain-in-a-box/master/install.ps1 | iex"

Mac

Installe d’abord Claude Code, puis, dans le Terminal :

git clone https://github.com/BrainInBox/brain-in-a-box.git
cd brain-in-a-box
./install.sh

Linux

Debian, Ubuntu : dans un terminal, sans sudo devant install.sh.

sudo apt install -y git curl
git clone https://github.com/BrainInBox/brain-in-a-box.git
cd brain-in-a-box
./install.sh

À la fin, l’installation affiche la suite, dont la personnalisation. Pour parler à Claude ensuite : ouvre un terminal dans le dossier de ton cerveau et tape claude. Pour mettre à jour sur Mac et Linux : cd brain-in-a-box && git pull && ./install.sh. Tous les détails dans le README (en anglais).
